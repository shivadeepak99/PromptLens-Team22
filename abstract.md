**Abstract:**

PromptLens addresses the lack of structured analysis in
AI prompt usage by transforming real prompt execution
logs into meaningful analytical insights. The project
focuses on collecting real prompts from sources such as
prompt libraries, chat history exports, and community
repositories, and converting them into a structured data
warehouse using ETL and star schema modeling. OLAP
operations are used to analyze historical prompt
behavior, while data mining techniques such as
classification, clustering, and association rule mining are
applied to discover patterns that influence prompt
effectiveness. The expected outcome is a system that
identifies successful prompt structures, optimal model
parameters, and common prompt patterns. These
insights are exposed through an API to guide better
prompt design and model usage based on data-driven
knowledge.
